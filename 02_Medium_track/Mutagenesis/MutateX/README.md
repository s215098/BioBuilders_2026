## setup

```bash
conda create -n mutatex-env "python>=3.10"
conda activate mutatex-env
conda install -c conda-forge setuptools biopython numpy matplotlib scipy six openpyxl pandas pyyaml
pip install logomaker "adjustText>=0.8" setuptools

cd mutatex
python setup.py install

```

MutateX needs to know the location of the FoldX binary and rotabase.txt file in order to work. Depending
on the version you are using, you might need to provide the binary file only. MutateX first tries to find these files looking at the content of the FOLDX_BINARY and FOLDX_ROTABASE system variables. Therefore, it is advisable to set these
system variables in the .profile or .bashrc file in your user's home, by adding the following lines:

export FOLDX_BINARY=/usr/local/foldx/foldx
export FOLDX_ROTABASE=/usr/local/foldx

and source it:

```bash
source .bashrc
```

### Requirements

#### FoldX

Download FoldX from https://foldxsuite.crg.eu (free registration required).

- Download the version for your OS
- Make the binary executable: `chmod +x foldx_*`
- Add it to your PATH or pass the full path via `--foldx`

## Running

To run, make a run_name_of_your_enzyme.sh script like this (from example/PTEN/run.sh):

```bash
mutatex 1D5R_noheatm.pdb \
	-p 4 \
	-m mutation_list.txt \
	-x /usr/local/foldx5/foldx \
	-f suite5 \
	-R repair_runfile_template.txt \
	-M mutate_runfile_template.txt \

# manual cleaning for this run - Obs! Not tried by Kristine, but should work since the files should be named the same.
cd mutations
find . -name runfile.txt | xargs rm
find . -name individual_list.txt | xargs rm
find . -name rotabase.txt | xargs rm
find . -name '*.pdb' | xargs rm
cd ..
tar cvzf mutations.tar.gz mutations
rm -rf mutations
```

and run it with

```bash
bash run_name_of_your_enzyme.sh
```

### The arguments are:

"-p","--pdb", dest="in_pdb", help="Input PDB file", required=True

"-d","--data-directory", dest="ddg_dir", type=str, help="Input DDG data directory", required=True

"-l","--mutation-list", dest="mutation_list", help="MutateX mutation list file", required=True

"-q","--position-list", dest="position_list", help="MutateX position list file", default=None

"-M","--multimers", dest="multimers", default=True, action='store_false', help="Do not use multimers (default: yes)"

"-b","--label-list", dest="labels", help="Residue label list generated by pdb2labels"

"-F","--font", dest='font',action='store', type=str, default=None, help="Use this font for plotting. If this isn't specified, the default font will be used."

"-f","--fontsize",dest='fontsize',action='store', type=int, default=8, help="Axis label font size"

"-v","--verbose", dest="verbose", action="store_true", default=False, help="Toggle verbose mode"

"-i","--title", dest='title', type=str, default=None, help="Title for the output image file"

"-c","--color", dest='mycolor', type=str, default="black", help="Color used for plotting"

"-s","--splice", dest='sv',action='store', type=int, default=20, help="Divide data in multiple plots, use -s residues per plot"

'-x', '--foldx-binary', dest="foldx_binary", action='store', type=str, default=foldx_binary_var, help="location of the FoldX binary (default: content of the FOLDX_BINARY system variable)"
